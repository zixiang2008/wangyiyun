# Contributing

Thank you for helping with this project.

## Best ways to help

- identify chips, ports, or debug interfaces from photos
- suggest safe next-step evidence collection
- review BLE / LAN probe results
- help classify whether recovery or repurposing is more realistic
- open issues with concrete tasks or hypotheses

## Please include when opening an issue

- what you noticed
- why it matters
- what evidence is still missing
- what the device owner should test next

## Evidence priorities

1. bottom label photos
2. mainboard front / back photos
3. `Mini-USB` enumeration behavior
4. router DHCP / hostname / MAC prefix
5. BLE scan output
6. LAN scan output

## Safety

- only work on hardware you legally own
- avoid destructive experiments unless clearly documented
- do not post secrets, home IPs, or personally sensitive data

# 贡献说明

感谢你愿意帮这个项目推进。

## 最有价值的参与方式

- 帮忙识别芯片、接口、调试口
- 给出下一步最值得采集的证据
- 看 BLE / 局域网扫描结果并判断方向
- 帮忙判断应优先“恢复原功能”还是“改造复用”
- 直接提 issue，写清楚假设和建议动作

## 提 issue 时建议带上

- 你发现了什么
- 为什么这条线索重要
- 还缺什么证据
- 建议设备持有人下一步测试什么

## 证据优先级

1. 底部铭牌照片
2. 主板正反面照片
3. `Mini-USB` 连接电脑后的表现
4. 路由器 DHCP / 主机名 / MAC 前缀
5. BLE 扫描结果
6. 局域网探测结果
