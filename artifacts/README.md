# Artifacts

Store collected evidence here.

Suggested structure:

- `photos/` — device exterior, labels, teardown images
- `network/` — scan output, DHCP notes, service discovery
- `audio/` — power-on prompts, pairing sounds, voice clips
- `notes/` — timelines, observations, manual notes

Please avoid uploading private information without review.

# 证据目录

这里用来存放后续采集到的证据。

建议结构：

- `photos/` — 外观、铭牌、拆机图
- `network/` — 扫描结果、DHCP 信息、服务发现记录
- `audio/` — 开机提示音、配网提示音、录音
- `notes/` — 时间线、观察记录、文字笔记

上传前请注意隐私信息脱敏。
