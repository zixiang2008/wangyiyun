# 图片建议命名

建议这样命名，后续更容易让别人看懂：

- `device-exterior-front.jpg` — 正面外观
- `device-exterior-side.jpg` — 侧面外观
- `bottom-label.jpg` — 底部铭牌
- `mainboard-front.jpg` — 主板正面
- `mainboard-back.jpg` — 主板背面
- `mini-usb-closeup.jpg` — Mini-USB 近照
- `debug-pads-closeup.jpg` — 调试点近照

每个区域最好同时放：

- 一张全景图
- 一张局部近照
