# 产品资料档案：网易三音云音箱

## 一、产品基本信息

- 产品名称：`网易三音云音箱`
- 英文名称：公开资料中常见为 `Netease Sing Cloud Speaker`
- 常见型号线索：`NS-CS1`
- 定位：网易云音乐深度绑定的智能音箱/音乐音箱
- 首发时间线：公开报道集中于 `2018年7月`

## 二、公开资料汇总

### 1) 发售与定价

根据公开报道可交叉得到：

- 京东众筹上线时间为 `2018年7月`
- 零售价常见表述为 `1399 元`
- 众筹价常见表述为 `799 元`

### 2) 面向用户的卖点

公开评测和报道反复提到：

- 更强调音质和网易云音乐内容，而不是“全能智能”
- 深度绑定网易云音乐推荐能力
- 面向喜欢听歌、依赖歌单推荐的用户

### 3) 已知声学/交互信息

公开资料显示：

- `2 × 1.5 英寸` 全频单元
- `1 × 3.5 英寸` 低音单元
- `6` 个拾音麦克风
- 顶部实体按键 + 旋转音量结构
- 正面有状态/灯效显示

### 4) 已知芯片/硬件线索

拆解资料中可见：

- SoC：`Allwinner R16-J`
- Wi‑Fi / BT 模组：`AP6236`
- 无线主芯片：`Broadcom BCM43436`
- 音频功放：`TI TPA3118`
- 音频 DSP / Codec：`ADAU1761`
- 顶部控制 MCU：`STM32F105`
- 供电：`20V 2A`
- 存储线索：
  - `SK hynix 4Gb DDR3L`
  - `MX30LF2G18AC-TI 2Gb Flash`

### 5) 对后续逆向很关键的结构线索

拆解资料中出现：

- `Mini-USB` 接口
- `Reset` 微动按键
- 主板上预留 `TF 卡插座位置`

这些都非常重要，因为它们意味着设备可能存在：

- 调试/刷写入口
- 产测/维护接口
- 固件落地/导出可能性

## 三、对逆向路线的判断

基于公开资料，我的判断是：

### 路线 A：恢复原设备联网能力

前提：

- 旧版 App 还能跑
- BLE 配网链路仍存在
- 云端关键接口未完全失效

难点：

- 官方入口可能已从新版 App 中移除
- 旧版 App 也可能依赖已下线服务

### 路线 B：找局域网控制接口

前提：

- 设备上电后仍能入网
- 局域网中仍暴露 HTTP / TCP / mDNS / SSDP / Cast 风格接口

收益：

- 一旦有本地控制能力，就能绕开官方 App 的一部分限制

### 路线 C：通过调试口/固件进入系统

前提：

- Mini-USB / UART / 测试点可用
- 系统没有完全封死

收益：

- 这是最有希望真正“复活”设备的路线
- 因为 `Allwinner R16` 常见于 Linux/Android 类设备，理论上比纯封闭 MCU 设备更有研究价值

### 路线 D：放弃原控制板，仅保留优秀音频硬件

如果原系统完全废弃，也可以考虑：

- 保留音腔、喇叭、功放、麦克风
- 更换主控板
- 改造成：
  - 网络音箱
  - Home Assistant 语音终端
  - 本地 TTS 终端
  - 智能体语音外设

这条路线不算“原机恢复”，但实用性可能最高。
