# 求助渠道清单

下面按“最可能找到对应高手”的优先级整理。

## A. 最值得优先发的中文渠道

### 1) GitHub

- 适合内容：
  - 建立主仓库
  - 挂 issue
  - 收集图片、日志、抓包、拆机资料
- 为什么优先：
  - 最适合长期协作
  - 能沉淀文档、脚本、结论
- 推荐动作：
  - 建公开仓库
  - README 首屏放问题定义、已知硬件、想要的帮助
  - 开 `Issues` 按专题收集

### 2) V2EX

- 入口建议：
  - `智能硬件`
  - `分享发现`
  - `程序员`
- 优势：
  - 有不少做嵌入式、系统、Home Assistant、硬改的人
  - 适合发“资料梳理 + 求合作”
- 发帖重点：
  - 标题别写成纯抱怨
  - 强调“资料已整理，欢迎懂 BLE / UART / 固件的朋友接手”

### 3) 吾爱破解（52pojie）

- 版块方向：
  - 软件安全
  - Android 逆向
  - 智能硬件/蓝牙相关内容延伸帖
- 优势：
  - 逆向、抓包、协议分析、APK 分析人群多
- 注意：
  - 版规严格
  - 主题要写成“协议研究/资料求助/设备复活”，避免情绪化标题

### 4) 数码之家

- 适合方向：
  - 拆机
  - 主板识别
  - UART / 测试点
  - 电路与接口判断
- 优势：
  - 很多动手型玩家
  - 对“电子垃圾复活”题材友好

### 5) 恩山无线论坛

- 适合方向：
  - OpenWrt
  - 路由抓包
  - 局域网服务发现
  - 嵌入式 Linux
- 优势：
  - 网络层、固件层用户密度高

### 6) Home Assistant 中文社区 / Hassbian 社区

- 适合方向：
  - 改造成局域网语音终端
  - 接入 Home Assistant
  - 智能体语音输出设备
- 优势：
  - 即便恢复不了原厂功能，也能给出改造路线

## B. 适合扩散的中文渠道

### 7) 小红书

- 用途：
  - 找同型号用户
  - 征集是否有人还留着旧 App、说明书、拆机图

### 8) B 站

- 用途：
  - 发短视频或图文动态
  - 让拆机/逆向 UP 主看到

### 9) 微博 / 超话 / 话题

- 用途：
  - @ 音频、拆机、数码博主
  - 搜集存量用户

### 10) 闲鱼

- 用途：
  - 搜同型号机器
  - 联系卖家索要底部标签、主板照片、是否可开机

## C. 英文/国际渠道

### 11) Reddit

- 推荐方向：
  - `r/hardwarehacking`
  - `r/AskElectronics`
  - `r/homeassistant`
  - `r/ReverseEngineering`
  - `r/Bluetooth`
- 适合内容：
  - 贴主板、芯片、接口照片
  - 询问 `Allwinner R16 + AP6236` 的典型调试路径

### 12) XDA Developers

- 适合方向：
  - Android / 嵌入式系统
  - Boot / UART / 调试接口

### 13) OpenWrt Forum

- 适合方向：
  - 如果最终目标转向“替换系统/替换主控方案”

### 14) Hackaday / Hackaday.io

- 适合方向：
  - 把项目包装成 “rescue abandoned smart speaker”
  - 容易吸引硬件改造玩家

## D. 定向联系的专业资源

### 15) 我爱音频网

- 理由：
  - 他们有这款产品的公开拆解文章
  - 社群里更可能有人认得这套方案

### 16) 全志 / 嵌入式 / 蓝牙相关技术群体

- 可搜索关键词：
  - `Allwinner R16`
  - `AP6236`
  - `BCM43436`
  - `ADAU1761`

## E. 渠道优先级建议

第一批建议：

1. GitHub
2. V2EX
3. 52pojie
4. 数码之家
5. 恩山

第二批建议：

6. Home Assistant 中文社区
7. B站 / 小红书 / 微博
8. Reddit / XDA / OpenWrt Forum

## F. 发帖时一定要带上的材料

- 设备外观图
- 底部铭牌图
- 已知硬件芯片清单
- 目前症状描述
- 你希望别人帮什么
- GitHub 仓库地址
- 你愿意继续配合测试这一点
