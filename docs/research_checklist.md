# 研究排查清单

## 一、先做无损排查

- 拍清楚底部铭牌
- 记录电源规格
- 观察是否有隐藏按键组合进入配网模式
- 用手机蓝牙扫描：
  - 看名称
  - 看 MAC
  - 看是 BLE 还是经典蓝牙
- 登录路由器后台，看是否出现新设备

## 二、局域网层

- 记录 DHCP 分配到的 IP
- 扫描常见端口
- 看有没有：
  - `80/443` Web
  - `23` Telnet
  - `22` SSH
  - `554` RTSP
  - `8008/8009` Cast 风格端口
  - `1883` MQTT
- 关注 mDNS / SSDP 广播内容

## 三、蓝牙层

- 记录广播名、RSSI、服务 UUID
- 如果能连 BLE，导出 GATT 服务表
- 查是否有 Wi‑Fi SSID / 密码写入特征值

## 四、硬件层

- 找螺丝位和卡扣位
- 查是否有：
  - UART 4pin/3pin
  - USB 调试点
  - eMMC / NAND 标识
  - 主控丝印
  - Wi‑Fi / BT 模组型号

## 五、逆向方向判断

- 如果是 Linux/Android：优先找串口和固件
- 如果是 BLE 配网设备：优先恢复 provisioning
- 如果有本地 HTTP API：优先做局域网控制脚本
- 如果只是云端闭环：需要更深入固件逆向
