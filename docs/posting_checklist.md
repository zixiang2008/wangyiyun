# Posting Checklist

## Before posting

- confirm the repo is public
- confirm images load in `README.md`
- confirm the main link uses:
  - `https://github.com/zixiang2008/wangyiyun`

## Best first-wave targets

1. V2EX
2. 52pojie
3. 数码之家
4. 恩山无线论坛
5. Reddit
6. X / Twitter

## What to include in every post

- what the device is
- why it is no longer usable
- known hardware clues
- what help is needed
- GitHub repo link

## After posting

- monitor replies for evidence requests
- upload new photos and logs into `artifacts/`
- turn useful replies into GitHub issues
- keep one source of truth in the repo

# 发帖检查清单

## 发帖前

- 确认 GitHub 仓库是公开的
- 确认 `README.md` 里的图片能正常显示
- 确认对外统一使用这个链接：
  - `https://github.com/zixiang2008/wangyiyun`

## 第一批优先渠道

1. V2EX
2. 52pojie
3. 数码之家
4. 恩山无线论坛
5. Reddit
6. X / Twitter

## 每个帖子都要带上

- 设备是什么
- 为什么现在基本不可用
- 已知硬件线索
- 你想请别人帮什么
- GitHub 仓库链接

## 发帖后

- 留意别人要你补什么证据
- 把新照片和日志上传到 `artifacts/`
- 把有价值的回复整理成 GitHub issue
- 始终让仓库作为唯一资料中心
