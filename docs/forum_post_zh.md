# 求助逆向 / 复活：网易三音云音箱已被官方入口放弃，想组织高手协作救活

大家好，我手里有一台很多年前高价购买的 **网易三音云音箱**（包装上英文名可能是 `NETEASE SING CLOUD SPEAKER`）。

现在遇到的问题是：

- 官方 App 已取消相关配网/入口
- 设备无法正常重新联网
- 没有 3.5mm 音频输入
- 也无法直接当普通蓝牙音箱使用
- 但设备本身硬件看起来还不错，支持：
  - 蓝牙
  - Wi‑Fi
  - 麦克风
  - 扬声器音质不错

我不想让它变成电子垃圾，所以把公开资料先整理成了一个协作项目，希望有逆向、嵌入式、蓝牙、网络协议、Home Assistant、硬件改造经验的朋友一起看看。

## 已整理到的关键信息

- 产品名称：网易三音云音箱
- 公开型号线索：`NS-CS1`
- 公开拆解资料显示主控可能是：`Allwinner R16-J`
- 无线模组线索：`AP6236 / BCM43436`
- 还有：
  - `Mini-USB` 接口
  - `Reset` 微动按键
  - 主板预留 `TF` 卡位
- 这说明它并不是完全没有研究价值的纯黑盒

## 想实现的方向

1. 恢复 BLE 配网或 Wi‑Fi 联网
2. 找到局域网控制/播放接口
3. 如果可能，改造成：
   - 本地网络音箱
   - 蓝牙播放终端
   - TTS 播放器
   - 智能体语音输出终端
