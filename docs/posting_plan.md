# 发帖执行方案

## 第一阶段：先建“主阵地”

先做 1 件事：

- 建一个公开 GitHub 仓库，把本目录全部上传

目的：

- 所有论坛帖都指向同一个资料中心
- 避免信息分散、反复解释

## 第二阶段：先打 5 个核心渠道

按这个顺序发：

1. GitHub 仓库上线
2. V2EX
3. 52pojie
4. 数码之家
5. 恩山无线论坛

理由：

- 这 5 个地方最容易碰到愿意真正动手的人

## 第三阶段：扩散找同型号用户

再发：

- B站动态
- 小红书
- 微博
- 闲鱼同款搜索

目标：

- 找旧用户
- 找旧 App 安装包
- 找说明书
- 找已拆机的人

## 第四阶段：国际求助

如果中文社区 1~2 周没有明显进展，再发：

- Reddit
- XDA
- OpenWrt Forum

## 标题建议

### 中文

- `求助逆向复活：网易三音云音箱被官方停服后基本报废，想组织大神一起救活`
- `资料已整理，求 BLE / UART / 固件高手接手：网易三音云音箱复活计划`

### 英文

- `Help wanted: revive an abandoned Netease smart speaker with BLE/Wi-Fi reverse engineering`
- `Reverse engineering request: Netease Sing Cloud Speaker (Allwinner R16 / AP6236)`

## 发帖正文结构

1. 先说设备是什么
2. 再说为什么废了
3. 再说你已经整理了哪些资料
4. 再说你希望别人具体帮什么
5. 最后放 GitHub 链接
