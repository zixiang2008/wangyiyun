Netease Sing Cloud Speaker Rescue

A public collaboration hub for reviving the abandoned Netease Sing Cloud Speaker （网易三音云音箱）.

GitHub Repository Open an Issue
Status Documentation, evidence collection, and public help request.
Goal Attract BLE, firmware, UART, embedded Linux, and hardware experts.
Not Yet A finished unlock, firmware image, or replacement app.

What We Know

  • Public clues mention Allwinner R16-J.
  • Wireless clues include AP6236 and BCM43436.
  • Teardown clues show Mini-USB, Reset, and reserved TF footprint.
  • The speaker has no practical 3.5mm input path and does not currently behave like a normal Bluetooth speaker.

Help Needed

  • BLE / Bluetooth reverse engineering
  • UART or debug port identification
  • Firmware extraction and inspection
  • Local network service discovery
  • Repurposing for Home Assistant or AI voice output
